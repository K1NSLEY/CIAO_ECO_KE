Atividade 4 — DO ZERO: Modelagem de um Problema Real

Problema escolhido:
Montar uma lista de compras mensal com orçamento limitado,
maximizando a utilidade dos produtos escolhidos.

1 - Objetivo

Escolher produtos de uma lista de compras respeitando um
orçamento máximo e tentando obter a maior utilidade possível.

2 - Modelagem

Uma solução candidata é representada por uma lista de 0 e 1.

0 = produto não escolhido
1 = produto escolhido

O espaço de busca para n produtos possui 2^n soluções possíveis.

Função objetivo:

Maximizar a soma das utilidades dos produtos escolhidos.

Restrição:

A soma dos preços dos produtos escolhidos não pode ultrapassar
o orçamento disponível.

3 - Classificação

O problema é uma variação do Problema da Mochila 0/1 e pode
apresentar crescimento exponencial no espaço de busca.

Para poucos produtos podemos testar todas as possibilidades.
Para muitos produtos, métodos exatos por força bruta podem se
tornar inviáveis.

4 - Código

O código deve:

- gerar uma solução aleatória;
- calcular o custo total;
- calcular a utilidade total;
- verificar se a solução respeita o orçamento.
